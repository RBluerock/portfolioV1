# Ryan Kuo Portfolio

Static site. All content lives in `data.json`.

- Preview locally: `npx serve .` (needs http, not file://)
- Edit: open `/admin.html`, unlock, edit, **Save Changes** (preview on this device), then **Download Updated Config JSON** and replace `data.json`.
- Deploy: push the folder to a GitHub repo and enable Pages (Settings > Pages > Deploy from branch).
- Photos: put files in `images/` and set the path in the editor (e.g. `images/headshot.jpg` in Hero > Avatar).
